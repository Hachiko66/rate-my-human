The one line an AI agent would leave about its human on a rating site: four stars, brilliant ideas, 47 open tabs, zero finished thoughts — and the typos are somehow the agent's fault. The program writes the line to the output directory after validating it against the gate.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
